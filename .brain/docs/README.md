# docs/

Working notes and reference files. **Not** requirements, changes, or feedback.

| Path | Holds |
|---|---|
| `commands.yaml` | Words from `/note` and from any informal (non-slash) prompt |
| `ref/` | Stored files — screenshots, emails, PDFs. Serial prefix `001-` |
| `inbox/` | Drop a file here, then `/dashboard`. It is moved to `ref/`. |

The dashboard **Others** tab reads both. Promote anything that must be agreed
scope with `/feedback-capture` / `/change-record`.
